# OpenAI 启动效果与龙娘背景实施计划

**目标**：在当前 Codex 的 Woodfish 中加入 OpenAI / Codex 开场，使用提供的静态龙娘图作为聊天背景。

**设计（按用户提供的 `dl.mp4` 修正）**：黑幕 OpenAI 标识 → 洗白 → 暖白技术档案底板 → 访问许可确认 → 身份确认 → 接收请求 → 读取权限 → 环形核验 → WELCOME TO / OPENAI CODEX → 色散转场 → 深色龙娘显影、左侧金属 OpenAI 大字与 HUD → 交叉淡出至聊天。前两步按钮或 Enter / 空格确认；右上角跳过与 Esc 全程可用。许可和身份只属于开场演出，不请求真实系统权限、不读取账户资料。第二幕通过用户静态图、扫描和缓慢推近完成，无视频素材。每页面一次，热更新不重复；关闭时恢复焦点并清理计时器。自动段默认约 26 秒，不计等待确认，可调节时长或关闭确认。
