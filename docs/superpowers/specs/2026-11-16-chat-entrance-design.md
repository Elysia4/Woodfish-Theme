# 开场结束后的聊天入场动效

用户已确认：只修改 OpenAI 第二幕结束后进入聊天的过渡，采用参考页的约 1.8 秒分层展开。

参考：https://scp-wiki-cn.wikidot.com/scp-3812 。提取其分隔线展开、区块依次显现、文字上移和图标落定的节奏，以当前 Codex 主题呈现。

正常播完、第二幕的「进入工作区」及 Enter / 空格触发相同过渡：开场短淡出，主区与侧栏横向展开，标题与消息轻移显现，输入框和按钮最后落定。Esc 和 SKIP 快速退出，不额外播放入场。减少动态、切后台或停用时立即结束入场并清理状态。

实现只给根节点添加临时状态，以稳定宿主选择器应用 CSS；不拆消息、不改变布局、不逐字动画。新会话、没有侧栏或正在其他页面时，存在的区块正常出现。1.8 秒后取消计时器并移除临时状态，焦点在离场开始时归还。

验证覆盖正常结束、点击与键盘进入、跳过、后台与减少动态、停用清理和每页面一次；独立预览复用实际插件和相同宿主标记。
